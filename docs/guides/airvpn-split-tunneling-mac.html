AirVPN split tunneling on Mac

AirVPN's own app, Eddie, can route by destination on the desktop (chosen IPs and ranges in or out of the tunnel), but not by app. AirVPN's staff say per-app splitting exists only in their Linux and Android clients. The Config Generator gives you standard WireGuard configs, though, and those can put a single Mac app on AirVPN while everything else stays on your normal connection.

Get a WireGuard config from AirVPN

  1. Sign in and open the Config Generator (Client Area → Config Generator).
  2. Pick WireGuard as the protocol, then the countries or servers you want.
  3. Click Generate and download the files. Each server comes as its own .conf, with long names like AirVPN_BE-Brussels_Columba_UDP-1637.conf.

Put one app on it with VPNonly

  1. Install VPNonly and open the ⋯ menu → Import WireGuard config….
  2. Choose the .conf, or select several (or the folder or zip they came in) at once. Pick the exit from the menu at the bottom.
  3. Search for an app, flip its switch. It relaunches once, then it's on the VPN and nothing else is.

AirVPN's configs include a PresharedKey, which the import handles without any extra step. Keys belong to a device in your AirVPN account (the Devices page). If you renew a device's key, its address changes too, so download fresh configs afterwards. An account allows five connections at once, and two devices can only use the same server if each has its own key.
