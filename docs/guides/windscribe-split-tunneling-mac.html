Windscribe split tunneling on Mac

Windscribe's macOS app already does split tunneling, in both directions: Exclusive leaves chosen apps off the VPN, Inclusive sends only chosen apps through it. It lives under Preferences → Connection → Split Tunneling and needs Windscribe's split-tunnel system extension switched on. If that works for you, it's included with your plan and there's no reason to buy anything else.

If you'd rather not run Windscribe's app at all, a paid plan also gets you WireGuard configs you can use with a per-app tool.

Get a WireGuard config from Windscribe

  1. Open Windscribe's WireGuard config generator and sign in. It needs Pro or a Build-A-Plan; free accounts can't use it, and Build-A-Plan only lists the locations you pay for.
  2. Pick a location, a port (443 if unsure), and New Key Pair.
  3. Click Download Config. You get one file per location, named like Windscribe-Tokyo-WG.conf.
  4. Want more than one country? Download again for each, and choose your existing key pair rather than a new one. An account can hold five key pairs, and the same pair works for any number of locations.

Put one app on it with VPNonly

  1. Install VPNonly and open the ⋯ menu → Import WireGuard config….
  2. Choose the .conf, or select several (or the folder you saved them in) at once. Pick the exit from the menu at the bottom.
  3. Search for an app, flip its switch. It relaunches once, then it's on the VPN and nothing else is.

Leave the file as it is. Windscribe's configs carry a PresharedKey, which the import handles, and their own guide warns against removing it or changing AllowedIPs. If a handshake never completes, check your Mac's clock; Windscribe notes a wrong system time breaks it.
